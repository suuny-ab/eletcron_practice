# AI 知识库助手

基于 RAG 技术的智能 Markdown 笔记管理桌面应用，集成大语言模型提供文档优化、智能编辑、知识问答等功能。

## 技术亮点

本项目针对大模型应用开发岗位设计，重点展示以下技术能力：

### 🔍 RAG 检索增强生成
- **三阶段检索架构**：向量检索(权重0.6) + BM25检索(权重0.4) + LLM重排序
- **语义文档切分**：基于Markdown标题层级的智能切分算法，避免语义断裂
- **RAG调试面板**：可视化展示检索流程各阶段结果，便于调优

### 💬 Prompt Engineering
- **多任务提示词模板**：6种任务类型（优化、建议、编辑、RAG问答、重排序、对话），工厂模式管理
- **用户自定义模板**：支持在配置文件中修改和扩展提示词模板
- **结构化输出**：使用Prompt约束LLM输出格式，提升解析可靠性

### 🌊 流式响应
- **SSE实时输出**：基于Server-Sent Events的流式响应架构
- **异步生成器**：AsyncGenerator模式实现高效流式传输
- **NDJSON格式**：标准化流式数据格式，支持增量渲染

### 🏗️ DDD 架构设计
- **四层架构**：应用层、领域层、基础设施层、核心层清晰分离
- **依赖注入容器**：自研轻量级DI容器，支持单例和瞬态生命周期
- **仓储模式**：抽象数据访问层，便于测试和扩展

### 📦 桌面应用打包
- **Electron + React**：现代化桌面应用架构
- **嵌入式Python**：无需用户安装Python环境
- **依赖预打包**：后端依赖打包到应用目录，开箱即用

## 核心功能

### 单文件编辑功能
- **AI建议**：类似智能IDE的ask功能，基于文档内容提供编辑建议
- **AI编辑**：使用AI根据用户要求自动编辑文档内容，提高编辑效率
- **一键排版**：AI自动优化Markdown文档结构和排版格式

### 知识库管理功能
- **智能索引**：自动索引Obsidian Vault中的Markdown文件
- **混合检索**：向量检索 + BM25检索的混合算法，提升召回质量
- **文件监控**：实时监控文件变更，自动更新索引

### RAG 问答功能
- **知识问答**：基于知识库检索的智能问答，支持流式输出
- **上下文注入**：自动检索相关文档片段作为LLM上下文
- **调试面板**：可视化展示检索、重排序各阶段结果

## 快速开始

### 环境要求

- Node.js 18+
- Python 3.11+
- 通义千问 API Key

### 安装步骤

```bash
# 1. 克隆仓库
git clone <repository-url>
cd test

# 2. 安装前端依赖
npm install

# 3. 安装后端依赖
cd backend
pip install -r requirements.txt

# 4. 配置API Key
# 首次启动会提示配置通义千问API Key和Obsidian Vault路径

# 5. 启动开发环境
cd ..
npm run dev
```

### 配置说明

配置文件位置：`~/.myapp/config.json`

```json
{
  "obsidian_vault_path": "/path/to/your/vault",
  "api_key": "your-api-key",
  "model_name": "qwen3-max",
  "prompts": {
    "optimize_system": "自定义优化提示词...",
    "advise_system": "自定义建议提示词..."
  }
}
```

## 项目总结

### 解决的问题

**个人知识管理痛点**：
- **存而不读**：大量笔记囤积，难以消化吸收
- **读而不精**：阅读笔记缺乏深度思考和整理
- **维护效率低**：手动编辑、排版耗时费力

**解决方案**：
- **AI 建议功能**：类似智能 IDE 的 ask 功能，提供智能编辑建议
- **AI 编辑功能**：自动化笔记编辑，提升编辑效率
- **一键排版**：自动优化 Markdown 结构，保证笔记格式统一
- **RAG 问答**：基于知识库的智能问答，快速检索知识

### 技术收获

**软件工程能力**：

- 测试驱动开发和质量保证

**全栈开发能力**：
