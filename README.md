# AI 知识库助手

基于 RAG 技术的智能 Markdown 笔记管理桌面应用，集成大语言模型提供文档优化、智能编辑、知识问答等功能。

## 技术亮点

### 🤖 统一 Agent 工作流
- **LangGraph 状态机**：基于条件路由的多节点工作流，支持 5 种意图类型
- **意图识别**：自动识别 chitchat/rag_query/doc_advise/doc_edit/doc_format
- **RAG 检索循环**：最多 3 轮检索（问题分析 → 混合检索 → 结果评估 → 查询重写）
- **权限系统**：assistant/editor 两级权限模型，控制文档操作
- **流式消息协议**：8 种消息类型（status/thinking/sources/chunk/diff/prompt/error/complete）

### 🔍 RAG 检索增强生成
- **三阶段检索架构**：向量检索(权重0.6) + BM25检索(权重0.4) + LLM重排序
- **语义文档切分**：基于Markdown标题层级的智能切分算法，避免语义断裂
- **增量索引**：文件变更监控 + Marker 同步机制，保证数据一致性
- **RAG调试面板**：可视化展示检索流程各阶段结果，便于调优

### 💬 会话记忆系统
- **JSONL 持久化**：对话历史按会话 ID 隔离存储
- **摘要滚动**：20 轮对话后自动触发摘要压缩，保持上下文窗口
- **会话元数据**：标题自动生成、轮次统计、文档引用追踪

### 📊 指标监控系统
- **MetricsCollector**：Counter 计数器 + Histogram 直方图 + TimeSeries 时序缓冲
- **HTTP 中间件**：自动采集请求数、耗时、状态码分布
- **多层级埋点**：HTTP/LLM/Agent/RAG/Memory 全链路指标
- **可视化仪表盘**：4 类时序趋势图 + 指标卡片 + 时间窗口选择（5/15/30/60 分钟）
- **JSONL 持久化**：7 天数据保留，启动时自动恢复

### 🌊 流式响应
- **SSE实时输出**：基于Server-Sent Events的流式响应架构
- **异步生成器**：AsyncGenerator模式实现高效流式传输
- **智能滚动**：80px 阈值检测，用户上翻时暂停自动滚动

### 🏗️ DDD 架构设计
- **四层架构**：应用层、领域层、基础设施层、核心层清晰分离
- **依赖注入容器**：自研轻量级DI容器，支持单例和瞬态生命周期
- **仓储模式**：抽象数据访问层，便于测试和扩展

### 📦 桌面应用打包
- **Electron + React**：现代化桌面应用架构
- **嵌入式Python**：无需用户安装Python环境
- **依赖预打包**：后端依赖打包到应用目录，开箱即用

## 核心功能

### AI 智能交互
- **闲聊对话**：通用问答，无需知识库检索
- **知识问答**：基于 RAG 检索的智能问答，支持多轮检索优化
- **文档建议**：结合文档内容和知识库，提供改进建议
- **文档编辑**：AI 自动编辑文档，输出 Unified Diff 格式
- **一键排版**：AI 自动优化 Markdown 结构和排版格式

### 知识库管理
- **自动索引**：启动时全量索引 + 运行时增量索引
- **混合检索**：向量检索 + BM25检索 的混合算法，提升召回质量
- **文件监控**：实时监控文件变更，自动更新索引
- **Marker 同步**：保证 index_marker.json 与向量库数据一致

### 系统监控
- **健康检查**：/api/health 系列端点，支持服务状态、实时指标、时序数据
- **指标仪表盘**：HTTP/LLM/RAG/Agent 四类趋势图 + 分组指标卡片
- **自动刷新**：10 秒轮询 + 手动刷新，时间窗口可选

## 快速开始

### 环境要求

- Node.js 18+
- Python 3.11+
- 通义千问 API Key

### 安装步骤

```bash
# 1. 克隆仓库
git clone <repository-url>
cd test

# 2. 安装前端依赖
npm install

# 3. 安装后端依赖
cd backend
pip install -r requirements.txt

# 4. 配置API Key
# 首次启动会提示配置通义千问API Key和Obsidian Vault路径

# 5. 启动开发环境
cd ..
npm run dev
```

### 配置说明

配置文件位置：`~/.myapp/config.json`

```json
{
  "obsidian_vault_path": "/path/to/your/vault",
  "api_key": "your-api-key",
  "model_name": "qwen3-max",
  "prompts": {
    "optimize_system": "自定义优化提示词...",
    "advise_system": "自定义建议提示词..."
  }
}
```

## 项目总结

### 解决的问题

**个人知识管理痛点**：
- **存而不读**：大量笔记囤积，难以消化吸收
- **读而不精**：阅读笔记缺乏深度思考和整理
- **维护效率低**：手动编辑、排版耗时费力

**解决方案**：
- **AI 建议功能**：类似智能 IDE 的 ask 功能，提供智能编辑建议
- **AI 编辑功能**：自动化笔记编辑，提升编辑效率
- **一键排版**：自动优化 Markdown 结构，保证笔记格式统一
- **RAG 问答**：基于知识库的智能问答，快速检索知识

### 技术收获

**大模型应用开发**：
- 掌握 RAG 检索增强生成的完整技术栈
- 理解 Prompt Engineering 的设计原则和技巧
- 实践流式响应和 SSE 技术
- LangGraph 状态机工作流设计

**可观测性工程**：
- 指标采集器设计（Counter/Histogram/TimeSeries）
- 时序数据持久化（环形缓冲 + JSONL）
- 前端可视化仪表盘（recharts）

**软件工程能力**：
- DDD 架构设计的实际应用
- 依赖注入和设计模式的实践
- 测试驱动开发和质量保证

**全栈开发能力**：
- Electron 桌面应用开发
- React 前端架构设计
- FastAPI 后端服务开发
